Build a Flutter application called GeoTimeline.

Purpose:
Scientists can track geological events on a map and timeline.

Features:
- Timeline overview screen
- Event detail screen
- Create event screen
- Event filtering
- Image upload using image_picker
- Google Maps integration
- Local storage using Hive

Event fields:
- title
- description
- category
- start date
- end date
- latitude
- longitude
- image

Categories:
- Earthquake
- Volcano
- Gas Emission
- Tsunami

Architecture:
- Provider state management
- Repository pattern
- Material 3

Pages:
- TimelinePage
- EventDetailPage
- CreateEventPage
- MapPage
